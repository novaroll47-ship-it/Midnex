# План: запуск платного скринера и модуль ботов

Состояние на 15.09.2026. Всё ниже уже на телефоне (перезайди в MIDNEX).

## Сделано

**Скринер (платный)**
- Без подписки видны 3 лучшие пары + карточка «Ещё N спредов скрыто — Открыть скринер $25/мес». Экран монеты закрыт.
- Настройки → Подписка: Скринер $25 (покупается), Стандарт $49 и Про $69 (с ценой, «Скоро»); сроки 1/3/6/12 мес по твоей сетке (65/120/210 и т.д.).
- Оплата: ⭐ звёзды Telegram (инвойс внутри приложения, доступ сразу) и USDT (TRC20 / BEP20 / ERC20 — твои кошельки; пользователь вставляет хэш, ты подтверждаешь в боте).
- За 3 дня до конца подписки бот напоминает.
- Ты (ID 534961097) — админ: видишь всё без подписки.

**Бот-админка** (напиши боту `/admin`)
- Кнопки: 📋 Заявки · 👥 Пользователи · ➕ Выдать доступ · 🚫 Отозвать · 🔎 Статус.
- Заявки на USDT приходят сразу с кнопками ✅ Подтвердить / ❌ Отклонить.
- «Выдать доступ»: бот спрашивает «@username 30» — отвечаешь, готово.

**Панель скринера**
- Вместо «Бот активен» — Бот «Спред» и Бот «Фандинг», серая точка, «Скоро», у каждого кнопка «Настроить».
- Экраны ботов спроектированы целиком, но заперты (приглушены, не реагируют), сверху пометка «Бот в разработке».
  - «Спред»: режим, исполнение (бумага/реал), биржи, мин. спред, плечо, объём, фандинг, риск-лимиты, механика входа, уведомления.
  - «Фандинг»: исполнение, биржи, вход (мин. разница ставок, мин. годовая доходность, макс. спред входа), удержание (мин. выплат, выход при падении разницы), размер, уведомления.
- Настройки → «Боты» ведут на те же экраны. Старые «Основные / Возможности / Риск / Уведомления» убраны.
- Память процесса ужата: ~900 МБ вместо 1.5 ГБ — на 2-ГБ сервер помещается.
