# Замена логотипа MidNex

## Файлы

| Файл | Для чего |
|---|---|
| `midnex-icon.svg` | Основная иконка: буква в тёмном круге + метки зазора. Для страниц, где иконка крупная (от ~48px) |
| `midnex-icon-simple.svg` | То же без меток. Для мелких размеров — метки там всё равно не читаются и превращаются в грязь |
| `midnex-mark.svg` | Только буква, фон прозрачный. Для шапки приложения рядом со словом MIDNEX |
| `midnex-mark-mono.svg` | Буква с `fill="currentColor"` — красится CSS-ом. Для мест, где нужен один цвет (иконка в навигации, светлая тема, favicon-маска) |
| `midnex-icon-512.png` | PNG 512×512 для аватарки Telegram-бота и канала (SVG там не принимается) |
| `midnex-icon-simple-512.png` | То же без меток |

## Что сделать

1. Заменить текущий логотип во всех местах проекта: иконка Mini App, favicon, шапка приложения, экран загрузки, всё, что использует старый знак.
2. **Правило выбора варианта по размеру:** от 48px и крупнее — `midnex-icon.svg`; меньше 48px — `midnex-icon-simple.svg`. Метки зазора на мелком размере сливаются в пятна.
3. Для шапки приложения: `midnex-mark.svg` + текст MIDNEX текущим шрифтом проекта, вес 700, `letter-spacing: .14em`, размер текста примерно в 0.7 от высоты знака.
4. Для светлой темы: использовать `midnex-mark-mono.svg` и задать `color: #00A85E` — на светлом фоне градиентный вариант теряет контраст.
5. Аватарку бота и канала в Telegram менять вручную через @BotFather и настройки канала — файл `midnex-icon-512.png`.

## Цвета знака

```
--logo-grad-from: #00B368   /* нижний левый угол градиента */
--logo-grad-to:   #6BEEB0   /* верхний правый */
--logo-bg:        #0D0F0E   /* тёмный круг */
--logo-mono:      #00A85E   /* одноцветная версия на светлом фоне */
```

Градиент идёт по диагонали: из левого нижнего угла в правый верхний (`x1=0 y1=1 x2=1 y2=0`).

## Чего не делать

- Не добавлять свечение/glow вокруг знака — у старого логотипа оно было, и именно оно делало его устаревшим.
- Не менять пропорции: буква построена так, что обе диагонали имеют одинаковую толщину, а развилка смещена влево на 2.5px намеренно — при растягивании по одной оси это ломается.
- Не вписывать слово MIDNEX внутрь круга — на аватарке 40px оно нечитаемо. Слово живёт только в горизонтальной версии.
